# Bean Haven

Bean Haven is a modern and responsive coffee shop website created using HTML and CSS.  
The project showcases a clean user interface, smooth navigation, and an aesthetically pleasing design focused on improving user experience.

Live Website:  
[Bean Haven Live Demo](https://bautistabernard.github.io/HUMCOM_FINAL_BEANHAVEN/?utm_source=chatgpt.com)

---

## Features

- Responsive web design
- Modern coffee shop UI
- Smooth navigation experience
- Interactive gallery section
- Organized layout structure
- Beginner-friendly code organization

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
