# 📦 Project Handoff: Bean Haven
 
## 📝 Overview
Bean Haven is a responsive coffee shop website created using HTML, CSS, and JavaScript.  
The project is designed to provide users with a clean and modern coffee shop browsing experience.
 
## 🛠 Tech Stack
* **Language:** HTML, CSS, JavaScript
* **Framework:** None
* **Database:** None
 
## ⚙️ Setup & Installation
Follow these steps to get the project running locally:

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files are complete.
4. Open `index.html` in your browser.
